Isolation(고립성/격리성)
데이터베이스 트랜잭션의 ACID 특성 중, 여러 트랜잭션이 동시에 실행될 때 각 트랜잭션이 다른 트랜잭션의 중간 연산 결과를 볼 수 없도록 보장하는 특성의 이름을 영문 용어로 쓰시오.

Isolation(격리성)은 여러 트랜잭션이 동시에 실행되더라도 각 트랜잭션이 마치 단독으로 실행되는 것처럼 다른 트랜잭션의 중간 수행 결과에 영향을 받지 않아야 한다는 특성이다. 이를 완벽히 보장하면 동시성이 떨어지므로 실제 DBMS는 Read Uncommitted, Read Committed, Repeatable Read, Serializable 등 여러 격리 수준(isolation level)을 제공해 성능과 일관성 사이에서 트레이드오프를 조절한다. 격리성이 낮으면 Dirty Read, Non-repeatable Read, Phantom Read 같은 이상 현상이 발생할 수 있다. 시험에서는 Atomicity(원자성), Consistency(일관성), Durability(지속성)와 혼동하지 않도록 각 특성의 정의를 명확히 구분해 암기해야 한다. 특히 Isolation은 동시성 제어(concurrency control)와 밀접하게 연결되는 개념으로 자주 함께 출제된다.

📎 함께 암기하기
  • Atomicity: 트랜잭션의 연산은 전부 실행되거나 전혀 실행되지 않아야 함
  • Consistency: 트랜잭션 수행 전후 데이터베이스가 일관된 상태를 유지해야 함
  • Durability: 커밋된 트랜잭션의 결과는 영구적으로 반영되어야 함
  • 격리 수준(Isolation Level): Read Uncommitted, Read Committed, Repeatable Read, Serializable 등 격리 강도 단계
  • Dirty Read: 다른 트랜잭션이 커밋하지 않은 데이터를 읽는 이상 현상

MAC (Mandatory Access Control)
주체와 객체에 사전에 부여된 보안등급(Security Label)을 비교하여 접근 허용 여부를 결정하며, 사용자가 임의로 접근 권한을 변경할 수 없고 시스템(보안관리자)이 중앙에서 접근 규칙을 강제하는 접근통제 모델의 명칭을 영문 약어로 쓰시오.

MAC(강제적 접근통제)는 주체(사용자)와 객체(자원)에 각각 보안등급(비밀, 대외비 등)을 부여하고, 이 레이블을 비교하여 접근을 허용하거나 거부하는 방식이다. 자원 소유자가 임의로 권한을 변경할 수 없고 시스템 관리자가 정한 정책에 따라 강제적으로 통제되는 것이 특징이며, 군사/정부 시스템처럼 보안등급이 명확한 환경에서 주로 사용된다. 이는 자원 소유자가 접근 권한을 자유롭게 부여할 수 있는 DAC(임의적 접근통제)와 대비되며, 사용자의 역할(Role)에 따라 권한을 부여하는 RBAC와도 구분된다. 대표적으로 벨-라파둘라(Bell-LaPadula) 모델이 기밀성을 보장하는 MAC의 한 예로 자주 출제된다.

📎 함께 암기하기
  • DAC: 자원 소유자가 접근권한을 임의로 부여하는 임의적 접근통제
  • RBAC: 사용자의 역할(Role)에 따라 권한을 부여하는 역할기반 접근통제
  • Bell-LaPadula 모델: 기밀성 유지를 위한 MAC 기반 모델로 No Read Up, No Write Down 원칙 적용
  • Biba 모델: 무결성 유지를 위한 모델로 No Write Up, No Read Down 원칙 적용
  • OTP: 매번 다른 일회용 비밀번호를 생성해 인증하는 기술

MITM(Man-In-The-Middle) 공격
공격자가 네트워크 패킷을 가로채어 송신자와 수신자 사이에서 몰래 통신 내용을 중계하며 도청하거나 변조하는 공격 기법을 영문 약어로 쓰시오.

MITM 공격은 통신하는 두 당사자 사이에 공격자가 끼어들어 패킷을 가로채고 도청 또는 변조하는 공격이다. ARP 스푸핑 등의 기법이 이를 수행하는 대표적인 방법으로 사용된다.

ON DELETE CASCADE
외래키 제약조건에서 부모 테이블의 행이 삭제될 때, 이를 참조하는 자식 테이블의 관련 행들도 자동으로 함께 삭제되도록 지정하는 옵션의 이름을 영문으로 쓰시오.

ON DELETE CASCADE는 외래키 제약조건을 정의할 때 사용하는 참조 무결성(referential integrity) 옵션으로, 부모 테이블의 레코드가 삭제되면 이를 참조하는 자식 테이블의 레코드도 자동으로 연쇄 삭제되게 한다. 이는 부모 키가 삭제되었는데 자식 테이블에 참조가 남아 고아 레코드(orphan record)가 생기는 무결성 위반 상황을 방지하기 위한 방법이다. 반대로 ON DELETE SET NULL은 부모가 삭제될 때 자식의 외래키 값을 NULL로 설정하고, ON DELETE RESTRICT(또는 NO ACTION)는 자식 레코드가 존재하면 부모 삭제 자체를 거부한다. 실기에서는 CASCADE, SET NULL, RESTRICT의 동작 차이를 구분하는 문제가 자주 나오므로 각 옵션이 삭제/갱신 시 어떻게 동작하는지 명확히 암기해야 한다. 무결성 제약조건 중에서도 이는 개체 무결성이 아니라 참조 무결성에 해당하는 개념임을 주의해야 한다.

📎 함께 암기하기
  • 참조 무결성(Referential Integrity): 외래키 값은 참조하는 테이블의 기본키 값과 일치하거나 NULL이어야 함
  • 개체 무결성(Entity Integrity): 기본키는 NULL이 될 수 없고 유일해야 함
  • ON DELETE SET NULL: 부모 삭제 시 자식의 외래키를 NULL로 설정
  • ON DELETE RESTRICT: 자식 레코드가 있으면 부모 삭제를 거부
  • 도메인 무결성(Domain Integrity): 속성 값이 정의된 도메인(자료형, 범위)을 만족해야 함

OSPF (Open Shortest Path First)
자신이 속한 라우터들의 링크 상태(비용, 대역폭 등) 정보를 전체 라우터에 플러딩 방식으로 전파하고, 각 라우터가 이를 바탕으로 다익스트라(Dijkstra) 알고리즘을 이용해 최단 경로 트리를 계산하는 내부 게이트웨이 프로토콜(IGP)은 무엇인가?

OSPF는 링크 상태(Link State) 알고리즘을 사용하는 대표적인 내부 게이트웨이 프로토콜로, 각 라우터가 자신과 연결된 링크의 상태 정보를 LSA(Link State Advertisement)를 통해 네트워크 전체에 플러딩하고, 이를 모아 만든 링크 상태 데이터베이스(LSDB)를 바탕으로 다익스트라 알고리즘을 수행해 최단 경로를 계산한다. 이는 이웃 라우터에게만 자신의 라우팅 테이블 전체를 주기적으로 전달하는 거리 벡터(Distance Vector) 방식의 RIP과 대비되는 특징이다. OSPF는 에어리어(Area) 개념을 도입해 대규모 네트워크를 계층적으로 관리할 수 있고 수렴 속도가 빠르다는 장점이 있다. 실기에서는 OSPF를 RIP(거리 벡터, 홉 카운트 기반)이나 BGP(자율 시스템 간 경로 벡터 프로토콜)와 혼동하지 않는 것이 중요하다.

📎 함께 암기하기
  • RIP: 홉 카운트 기반의 거리 벡터 라우팅 프로토콜
  • BGP: 자율 시스템(AS) 간 경로를 교환하는 외부 게이트웨이 프로토콜
  • IGP/EGP: 자율 시스템 내부용/외부용 라우팅 프로토콜 구분
  • 다익스트라 알고리즘: 최단 경로를 계산하는 그래프 알고리즘
  • ICMP: 네트워크 상태 진단 및 오류 메시지를 전달하는 프로토콜
출제일: 2026-10-14
TCP
OSI 7계층 중 전송 계층(4계층)에서 동작하며, 연결 지향적이고 신뢰성 있는 데이터 전송을 보장하는 프로토콜은 무엇인가?

TCP(Transmission Control Protocol)는 3-way handshake를 통해 연결을 설정하고, 순서 제어와 오류 검출 및 재전송을 통해 신뢰성 있는 데이터 전송을 보장한다. 이는 비연결형이며 신뢰성을 보장하지 않는 UDP와 대비된다.

VLSM (Variable Length Subnet Mask)
하나의 네트워크 대역을 필요에 따라 서로 다른 크기의 서브넷으로 나누어, IP 주소를 효율적으로 할당할 수 있도록 서브넷 마스크의 길이를 가변적으로 적용하는 서브네팅 기법을 가리키는 용어(약어)를 쓰시오.

VLSM은 하나의 네트워크를 여러 서브넷으로 나눌 때, 각 서브넷에 필요한 호스트 수에 맞춰 서로 다른 길이의 서브넷 마스크를 적용하는 기법입니다. 기존의 고정 길이 서브넷 마스킹(FLSM)은 모든 서브넷을 동일한 크기로 나누어 IP 주소 낭비가 발생하지만, VLSM은 필요한 만큼만 주소를 할당하여 주소 공간을 효율적으로 사용합니다. CIDR 표기법(예: /24, /27)과 함께 사용되며, 라우팅 프로토콜 중 RIPv1과 같이 클래스 기반 프로토콜은 VLSM을 지원하지 않고 OSPF, EIGRP, RIPv2 같은 클래스리스 프로토콜이 이를 지원한다는 점이 시험에서 자주 출제됩니다. 실기에서는 특정 서브넷 요구사항이 주어졌을 때 VLSM을 적용해 서브넷을 나누는 계산 문제와 함께 출제되는 경우가 많습니다.

📎 함께 암기하기
  • CIDR: 클래스 구분 없이 네트워크/호스트 비트를 자유롭게 나누는 주소 할당 방식
  • FLSM: 고정 길이로 동일한 크기의 서브넷만 생성하는 방식
  • NAT: 사설 IP와 공인 IP를 변환해주는 주소 변환 기술
  • 서브넷 마스크: 네트워크 부분과 호스트 부분을 구분하는 32비트 값
  • 라우팅 프로토콜: OSPF, RIP 등 경로 정보를 교환하는 프로토콜
출제일: 2026-10-13
공개키 암호화(비대칭키 암호화) 방식
암호화와 복호화에 서로 다른 키(공개키/개인키 쌍)를 사용하며, 키 분배 문제를 해결하지만 대칭키 방식보다 연산 속도가 느린 암호화 방식을 무엇이라 하는가?

공개키 암호화 방식은 서로 다른 두 개의 키, 즉 공개키와 개인키를 한 쌍으로 사용한다. 데이터를 암호화할 때 공개키를 사용하면 그 쌍이 되는 개인키로만 복호화할 수 있어 키를 공개해도 안전하게 분배할 수 있다는 장점이 있다. 반면 대칭키 암호화 방식은 암복호화에 동일한 키를 사용하므로 속도는 빠르지만 키 분배와 관리가 어렵다는 문제가 있다. 대표적인 공개키 알고리즘으로는 RSA, ECC가 있으며, 대칭키 알고리즘으로는 DES, AES, SEED 등이 있다. 실기에서는 흔히 두 방식을 혼합한 하이브리드 암호 시스템(예: 세션키를 공개키로 암호화하여 전달한 뒤 실제 데이터는 대칭키로 암호화)도 함께 출제되므로 구분해서 암기해야 한다.

📎 함께 암기하기
  • 대칭키 암호화: 암복호화에 동일한 키를 사용하며 속도가 빠름(DES, AES, SEED)
  • RSA: 소인수분해의 어려움에 기반한 대표적 공개키 알고리즘
  • 해시 함수: 임의 길이 입력을 고정 길이 출력으로 변환하는 일방향 함수(MD5, SHA)
  • 전자서명: 공개키 암호화를 응용해 송신자 인증과 무결성을 보장하는 기술
  • 하이브리드 암호시스템: 세션키 교환은 공개키, 데이터 암호화는 대칭키로 처리하는 혼합 방식

라우팅 프로토콜(Routing Protocol)
네트워크 계층에서 동작하며, IP 주소를 기반으로 송신 호스트가 목적지까지의 최적 경로를 설정하는 데 사용되는 프로토콜을 통칭하는 용어를 쓰시오. (예: RIP, OSPF 등이 속하는 상위 개념)

라우팅 프로토콜은 네트워크 계층(OSI 3계층)에서 라우터 간 경로 정보를 교환하여 최적의 패킷 전달 경로를 결정하는 데 사용되는 프로토콜의 총칭이다. RIP, OSPF, BGP 등이 대표적인 예이다.

출제일: 2026-10-05
서브네팅(Subnetting)
하나의 네트워크 대역을 서브넷 마스크를 이용해 여러 개의 작은 네트워크로 분할하여 IP 주소를 효율적으로 사용하고 트래픽을 분리하는 기법을 무엇이라 하는가?

서브네팅은 하나의 큰 네트워크 주소 공간을 서브넷 마스크를 조정하여 여러 개의 작은 논리적 네트워크(서브넷)로 나누는 기법이다. 이를 통해 IP 주소의 낭비를 줄이고 브로드캐스트 도메인을 축소해 네트워크 성능과 보안을 향상시킬 수 있다. 서브넷 마스크의 네트워크 비트를 늘릴수록 서브넷의 개수는 늘어나지만 각 서브넷에 할당 가능한 호스트 수는 줄어든다. CIDR(Classless Inter-Domain Routing) 표기법은 이러한 서브넷 마스크를 '/24'와 같이 접두사 길이로 간략히 표현하는 방식으로, 클래스 기반 주소 체계의 한계를 극복하기 위해 도입되었다. 실기에서는 특정 IP와 서브넷 마스크가 주어졌을 때 네트워크 주소, 브로드캐스트 주소, 사용 가능한 호스트 수를 계산하는 문제로 자주 출제되므로 비트 연산 계산법을 함께 익혀야 한다.

참조 무결성(Referential Integrity)2번 출제

패킷(Packet)
OSI 7계층 중 네트워크 계층(3계층)에서 라우터가 IP 주소를 기반으로 경로를 설정하고 전달하는 데이터 전송 단위(PDU)를 무엇이라 하는가?

OSI 7계층과 TCP/IP 계층은 계층마다 데이터 전송 단위(PDU)가 다르며, 물리 계층은 비트(Bit), 데이터 링크 계층은 프레임(Frame), 네트워크 계층은 패킷(Packet), 전송 계층은 세그먼트(Segment, TCP) 또는 데이터그램(Datagram, UDP)이라 부른다. 네트워크 계층은 IP 주소를 이용한 논리적 주소 지정과 라우팅을 담당하며, 라우터가 이 계층에서 동작하여 패킷 단위로 최적 경로를 결정해 전달한다. 실기에서는 각 계층의 대표 장비(물리-리피터/허브, 데이터링크-스위치/브리지, 네트워크-라우터, 전송 이상-게이트웨이)와 PDU 명칭을 짝지어 묻는 문제가 자주 나오므로 계층별 PDU와 장비를 함께 암기해야 한다. 또한 TCP/IP 4계층 모델에서는 OSI의 물리+데이터링크 계층이 네트워크 액세스 계층으로 통합된다는 점도 자주 비교되는 포인트이다.

팩토리 메서드 패턴(Factory Method Pattern)2번 출제
객체를 생성하는 과정을 캡슐화하여, 서브클래스에서 어떤 클래스의 인스턴스를 생성할지 결정하도록 하는 생성 패턴으로, 'new' 연산자 직접 호출을 피하고 객체 생성을 하위 클래스에 위임하는 디자인 패턴의 이름을 쓰시오.

팩토리 메서드 패턴은 객체 생성 로직을 서브클래스로 위임하여 클라이언트 코드가 구체적인 클래스를 알 필요 없게 만드는 생성 패턴이다. GoF 디자인 패턴 중 생성 패턴(Creational Pattern)에 속한다.
