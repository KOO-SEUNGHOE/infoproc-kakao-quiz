TCP
OSI 7계층 중 전송 계층(4계층)에서 동작하며, 연결 지향적이고 신뢰성 있는 데이터 전송을 보장하는 프로토콜은 무엇인가?

TCP(Transmission Control Protocol)는 3-way handshake를 통해 연결을 설정하고, 순서 제어와 오류 검출 및 재전송을 통해 신뢰성 있는 데이터 전송을 보장한다. 이는 비연결형이며 신뢰성을 보장하지 않는 UDP와 대비된다.

세션 하이재킹(Session Hijacking)
공격자가 정상적인 사용자인 것처럼 속여 TCP 세션을 가로채고, 서버와 클라이언트 사이의 통신에 끼어들어 인증을 우회하고 데이터를 조작하거나 탈취하는 공격 기법을 무엇이라고 하는가?

세션 하이재킹은 정상 사용자의 세션 식별자(세션 ID)를 가로채거나 예측하여 이미 인증된 세션을 탈취하는 공격입니다. 공격자는 이를 통해 별도의 인증 과정 없이 사용자의 권한으로 시스템에 접근할 수 있게 됩니다. TCP 시퀀스 번호를 추측하여 세션을 가로채는 방식이 대표적입니다.

애자일(Agile)
요구사항을 작은 단위의 기능으로 나누어 짧은 주기(보통 1~4주) 단위로 설계-개발-테스트를 반복하며 점진적으로 소프트웨어를 완성해가는 개발 방법론을 무엇이라 하는가?

애자일 방법론은 짧은 반복 주기(스프린트/이터레이션)를 통해 고객 피드백을 빠르게 반영하면서 점진적으로 소프트웨어를 개발하는 방식이다. 대표적으로 스크럼(Scrum), XP(eXtreme Programming) 등이 있다.

애자일(Agile) 방법론3번 출제
소프트웨어 개발 과정에서 요구사항 분석, 설계, 구현, 테스트 등의 전체 과정을 짧은 주기(이터레이션)로 반복하면서 점진적으로 완성도를 높여가는 개발 방법론으로, 고객과의 지속적인 협업과 변화에 대한 유연한 대응을 강조하는 방법론을 무엇이라 하는가?

애자일 방법론은 폭포수 모델과 달리 짧은 반복 주기(스프린트)를 통해 소프트웨어를 점진적으로 개발하며, 고객 피드백을 빠르게 반영하고 변화하는 요구사항에 유연하게 대응하는 것을 핵심 가치로 한다. 대표적으로 스크럼(Scrum), XP(eXtreme Programming) 등이 있다.

응집도(Cohesion)
모듈 내부의 처리 요소들이 서로 관련이 있는 정도를 나타내며, 값이 높을수록 모듈의 독립성과 재사용성이 좋아지는 소프트웨어 설계 품질 지표를 무엇이라 하는가?

응집도는 모듈 내부 구성 요소들이 하나의 목적을 위해 얼마나 밀접하게 관련되어 있는지를 나타내는 척도이다. 응집도가 높을수록 모듈의 독립성이 강해지고 유지보수가 쉬워지므로 좋은 설계로 평가된다. 결합도와 반대로 응집도는 높을수록 바람직하다.

정규화(Normalization)3번 출제
데이터베이스 설계에서 하나의 릴레이션(테이블)에 속성 간의 함수적 종속 관계를 분석하여, 데이터의 중복을 최소화하고 삽입/삭제/갱신 이상(anomaly)을 방지하기 위해 테이블을 분해해 나가는 과정을 무엇이라 하는가?

정규화는 함수적 종속성을 기반으로 테이블을 여러 개로 분해하여 데이터 중복을 줄이고 이상 현상을 방지하는 데이터베이스 설계 기법이다. 1정규형부터 BCNF, 4정규형 등 단계적으로 진행된다.

제2정규형(2NF)
릴레이션에서 기본키가 아닌 모든 속성이 기본키에 대해 완전 함수적 종속(부분 함수적 종속 제거)을 만족하도록 분해하는 정규화 단계를 무엇이라 하는가?

제1정규형을 만족한 릴레이션에서 부분 함수적 종속을 제거하여 모든 비주요 속성이 기본키 전체에 완전 함수적 종속되도록 만드는 과정이 제2정규형이다. 이는 복합키를 가진 테이블에서 특정 속성이 키의 일부에만 종속되는 문제를 해결한다.

제3정규형(3NF)2번 출제
관계형 데이터베이스에서 하나의 릴레이션에 있는 속성들 간에 기본키가 아닌 속성이 다른 기본키가 아닌 속성에 종속되는 현상을 제거하여, 이행적 함수 종속을 제거하는 정규화 단계를 무엇이라 하는가?

제3정규형은 제2정규형을 만족하면서 기본키가 아닌 모든 속성이 기본키에 대해 이행적 함수 종속이 되지 않도록 하는 정규화 단계이다. 즉, A→B, B→C인 경우 A→C의 이행적 종속을 제거하는 과정이다.

팩토리 메서드 패턴(Factory Method Pattern)
객체 생성 방식을 서브클래스에서 결정하도록 하여, 객체 생성 로직을 캡슐화하는 생성 패턴으로, 부모 클래스에서 객체 생성을 위한 인터페이스만 정의하고 실제 생성은 자식 클래스에 위임하는 디자인 패턴의 이름은 무엇인가?

팩토리 메서드 패턴은 객체 생성을 캡슐화하여 상위 클래스에서는 인터페이스만 정의하고, 실제 어떤 클래스의 인스턴스를 만들지는 하위 클래스가 결정하도록 하는 생성 패턴입니다. 이를 통해 객체 생성 코드와 사용 코드를 분리하여 유연성과 확장성을 높일 수 있습니다.
