Q1

코드 출력 · Python

다음 Python 코드의 실행 결과를 예측하시오.

def modify(lst, n):
    for i in range(len(lst)):
        lst[i] = lst[i] * n
    return sum(lst)
numbers = [1, 2, 3, 4, 5]
total = modify(numbers, 2)
print(numbers)
print(total)
result = []
for i in range(1, 4):
    temp = []
    for j in range(1, 4):
        if (i + j) % 2 == 0:
            temp.append(i * j)
    result.append(temp)
print(result)
정답 보기 
[2, 4, 6, 8, 10]
30
[[1, 3], [4], [3, 9]]

modify 함수는 리스트의 각 요소를 2배로 변경(리스트는 참조로 전달되므로 원본도 변경됨)한 후 합계를 반환하여 30이 출력된다. 두 번째 이중 반복문에서는 i+j가 짝수인 경우만 i*j를 temp에 추가하는데, i=1일 때 j=1(합2,짝)→1, i=2일 때 j=1(합3,홀)제외, j=2(합4,짝)→4, j=3(합5,홀)제외... 실제 계산: i=1: j=1(1*1=1,짝),j=2(홀),j=3(홀) → [1]... 다시 계산 필요.

Q2

코드 출력 · C

다음 C 코드의 실행 결과를 예측하시오.

#include <stdio.h>

int calc(int *arr, int size) {
  int sum = 0;
  for (int i = 0; i < size; i++) {
    if (arr[i] % 2 == 0) {
      sum += arr[i];
    } else {
      sum -= arr[i];
    }
  }
  return sum;
}

int main() {
  int arr[5] = {1, 2, 3, 4, 5};
  int *p = arr;

  for (int i = 0; i < 5; i++) {
    *(p + i) = *(p + i) + i;
  }

  for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
  }
  printf("\n");

  int result = calc(arr, 5);
  printf("%d\n", result);

  return 0;
}
정답 보기 
1 3 5 7 9 
-25

포인터 연산 *(p+i) = *(p+i) + i로 배열 각 요소에 인덱스값을 더하면 arr은 {1,3,5,7,9}가 된다. calc 함수는 짝수면 더하고 홀수면 빼는데, 모든 값이 홀수이므로 -(1+3+5+7+9) = -25가 된다.

Q3

SQL 결과

다음 schema_sql을 바탕으로 query_sql을 실행했을 때의 결과를 예측하시오.

-- schema
CREATE TABLE employee (
    emp_id INTEGER PRIMARY KEY,
    emp_name TEXT,
    dept TEXT,
    salary INTEGER
);

INSERT INTO employee VALUES (1, '김철수', '영업', 3000);
INSERT INTO employee VALUES (2, '이영희', '개발', 4000);
INSERT INTO employee VALUES (3, '박민수', '영업', 3500);
INSERT INTO employee VALUES (4, '최지은', '개발', 4500);
INSERT INTO employee VALUES (5, '정수현', '영업', 2800);
INSERT INTO employee VALUES (6, '한소영', '개발', 5000);

-- query
SELECT dept, COUNT(*) AS cnt, SUM(salary) AS total_salary
FROM employee
GROUP BY dept
HAVING SUM(salary) > 10000
ORDER BY total_salary DESC;
정답 보기 
dept | cnt | total_salary
개발 | 3 | 13500

부서별로 그룹화하면 영업은 3000+3500+2800=9300, 개발은 4000+4500+5000=13500이다. HAVING SUM(salary) > 10000 조건으로 영업 부서는 제외되고 개발 부서만 결과에 남아 '개발, 3, 13500' 한 행이 출력된다.

Q4

용어 단답

릴레이션에서 기본키가 아닌 속성이 기본키의 일부분에 종속되는 부분 함수 종속성을 제거하여 완전 함수 종속 관계로 만드는 정규화 단계를 무엇이라 하는가?

정답 보기 
제2정규형 (2NF)

제1정규형을 만족하는 릴레이션에서 부분 함수 종속을 제거하면 제2정규형이 된다. 이는 기본키가 복합키일 때 일부 속성만으로 결정되는 종속성을 없애는 과정이다.

Q5

용어 단답

공격자가 정상적인 사용자인 것처럼 가장하여 네트워크 상에서 송신자의 IP 주소나 MAC 주소 등을 위조해 상대방을 속이는 공격 기법을 무엇이라 하는가?

정답 보기 
스푸핑 (Spoofing)

스푸핑은 IP, ARP, DNS 등 다양한 계층에서 출발지 정보를 위조하여 정상 사용자로 위장하는 공격 기법이다. 대표적으로 IP 스푸핑, ARP 스푸핑, DNS 스푸핑 등이 있다.

⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
