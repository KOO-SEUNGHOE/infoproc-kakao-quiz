2026-10-14 실기 문제

Q1

용어 단답

자신이 속한 라우터들의 링크 상태(비용, 대역폭 등) 정보를 전체 라우터에 플러딩 방식으로 전파하고, 각 라우터가 이를 바탕으로 다익스트라(Dijkstra) 알고리즘을 이용해 최단 경로 트리를 계산하는 내부 게이트웨이 프로토콜(IGP)은 무엇인가?

정답 보기 
OSPF (Open Shortest Path First)

OSPF는 링크 상태(Link State) 알고리즘을 사용하는 대표적인 내부 게이트웨이 프로토콜로, 각 라우터가 자신과 연결된 링크의 상태 정보를 LSA(Link State Advertisement)를 통해 네트워크 전체에 플러딩하고, 이를 모아 만든 링크 상태 데이터베이스(LSDB)를 바탕으로 다익스트라 알고리즘을 수행해 최단 경로를 계산한다. 이는 이웃 라우터에게만 자신의 라우팅 테이블 전체를 주기적으로 전달하는 거리 벡터(Distance Vector) 방식의 RIP과 대비되는 특징이다. OSPF는 에어리어(Area) 개념을 도입해 대규모 네트워크를 계층적으로 관리할 수 있고 수렴 속도가 빠르다는 장점이 있다. 실기에서는 OSPF를 RIP(거리 벡터, 홉 카운트 기반)이나 BGP(자율 시스템 간 경로 벡터 프로토콜)와 혼동하지 않는 것이 중요하다.

📎 함께 암기하기
  • RIP: 홉 카운트 기반의 거리 벡터 라우팅 프로토콜
  • BGP: 자율 시스템(AS) 간 경로를 교환하는 외부 게이트웨이 프로토콜
  • IGP/EGP: 자율 시스템 내부용/외부용 라우팅 프로토콜 구분
  • 다익스트라 알고리즘: 최단 경로를 계산하는 그래프 알고리즘
  • ICMP: 네트워크 상태 진단 및 오류 메시지를 전달하는 프로토콜
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

Q2

용어 단답

OSI 7계층 중 네트워크 계층(3계층)에서 라우터가 IP 주소를 기반으로 경로를 설정하고 전달하는 데이터 전송 단위(PDU)를 무엇이라 하는가?

정답 보기 
패킷(Packet)

OSI 7계층과 TCP/IP 계층은 계층마다 데이터 전송 단위(PDU)가 다르며, 물리 계층은 비트(Bit), 데이터 링크 계층은 프레임(Frame), 네트워크 계층은 패킷(Packet), 전송 계층은 세그먼트(Segment, TCP) 또는 데이터그램(Datagram, UDP)이라 부른다. 네트워크 계층은 IP 주소를 이용한 논리적 주소 지정과 라우팅을 담당하며, 라우터가 이 계층에서 동작하여 패킷 단위로 최적 경로를 결정해 전달한다. 실기에서는 각 계층의 대표 장비(물리-리피터/허브, 데이터링크-스위치/브리지, 네트워크-라우터, 전송 이상-게이트웨이)와 PDU 명칭을 짝지어 묻는 문제가 자주 나오므로 계층별 PDU와 장비를 함께 암기해야 한다. 또한 TCP/IP 4계층 모델에서는 OSI의 물리+데이터링크 계층이 네트워크 액세스 계층으로 통합된다는 점도 자주 비교되는 포인트이다.

📎 함께 암기하기
  • 세그먼트: 전송 계층(TCP)의 데이터 단위
  • 프레임: 데이터 링크 계층의 데이터 단위
  • TCP/IP 4계층: OSI 7계층을 4단계로 단순화한 모델
  • 캡슐화: 상위 계층 데이터에 헤더를 추가하며 하위 계층으로 전달하는 과정
  • 라우터: 네트워크 계층에서 경로를 설정하는 장비
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
