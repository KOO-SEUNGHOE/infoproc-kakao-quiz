2026-10-22 실기 문제

Q1

용어 단답

주체와 객체에 보안 등급(Security Label)을 부여하고, 관리자가 정한 정책에 따라 주체가 자신의 등급보다 낮은 보안 수준의 정보를 기록하지 못하도록 하며(No Write Down), 자신의 등급보다 높은 수준의 정보를 읽지 못하도록(No Read Up) 강제하는 접근통제 모델을 무엇이라 하는가? (벨-라파듈라 모델이 대표적으로 구현하는 이 접근통제 방식의 명칭을 쓰시오)

정답 보기 
MAC (강제적 접근통제, Mandatory Access Control)

MAC은 시스템이 사전에 정의한 보안 등급과 규칙에 따라 접근 권한을 강제로 통제하는 방식으로, 주체(사용자)나 객체(자원)의 소유자가 임의로 권한을 변경할 수 없다는 점이 특징이다. 대표적으로 벨-라파듈라(Bell-LaPadula) 모델은 기밀성을 보장하기 위해 No Read Up(낮은 등급 주체가 높은 등급 객체를 읽을 수 없음)과 No Write Down(높은 등급 주체가 낮은 등급 객체에 쓸 수 없음) 규칙을 적용한다. 반대로 비바(Biba) 모델은 무결성을 보장하기 위해 반대 방향의 규칙(No Write Up, No Read Down)을 적용한다는 점에서 혼동하지 않도록 주의해야 한다. 임의적 접근통제(DAC)는 객체의 소유자가 권한을 임의로 부여할 수 있다는 점에서 MAC과 대조되며, 역할기반접근통제(RBAC)는 사용자의 역할(Role)에 따라 권한을 부여하는 방식으로 또 다른 분류에 속한다.

📎 함께 암기하기
  • DAC: 객체 소유자가 임의로 접근 권한을 설정하는 임의적 접근통제
  • RBAC: 사용자의 역할에 따라 권한을 부여하는 역할기반 접근통제
  • Bell-LaPadula 모델: 기밀성 보장을 위한 No Read Up, No Write Down 규칙의 MAC 모델
  • Biba 모델: 무결성 보장을 위한 No Write Up, No Read Down 규칙의 모델
  • OTP: 매번 다른 일회용 비밀번호를 생성해 인증하는 기술
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

Q2

용어 단답

화이트박스 테스트 기법 중, 프로그램 내 모든 가능한 실행 경로(루프의 반복을 포함한 독립적인 경로)를 수학적으로 산출하여 테스트 케이스를 설계하는 커버리지 기법으로, 흐름 그래프(Flow Graph)의 사이클로매틱 복잡도(Cyclomatic Complexity)를 기반으로 최소 테스트 케이스 수를 결정하는 이 기법의 명칭을 쓰시오.

정답 보기 
기본 경로 테스트(Basis Path Testing)

기본 경로 테스트는 화이트박스 테스트 기법 중 하나로, 프로그램의 제어 흐름을 그래프로 표현한 뒤 맥케이브(McCabe)가 제안한 사이클로매틱 복잡도 공식(V(G) = E - N + 2, 간선 수 E, 노드 수 N)을 이용해 독립적인 실행 경로의 개수를 계산하고, 그 수만큼의 테스트 케이스를 설계해 모든 독립 경로를 최소 한 번씩 실행하도록 한다. 이는 조건문과 반복문이 복잡하게 얽힌 코드에서 빠짐없이 경로를 검증하기 위한 체계적 방법이다. 화이트박스 테스트의 다른 기법인 조건 커버리지나 분기 커버리지와 달리, 기본 경로 테스트는 전체 경로의 수를 정량적으로 산출한다는 점이 특징이다. 블랙박스 테스트 기법인 동치 분할이나 경계값 분석과는 달리 내부 로직(소스 코드)의 구조를 직접 분석해야 한다는 점에서 명확히 구분된다.

📎 함께 암기하기
  • 문장 커버리지: 모든 실행 가능한 문장을 최소 한 번 실행하는 커버리지 기법
  • 분기 커버리지: 모든 조건문의 참/거짓 분기를 각각 한 번씩 실행
  • 조건/분기 커버리지: 개별 조건식과 분기 결과를 모두 커버
  • 동치 분할 테스트: 입력 데이터를 유효/무효 클래스로 나누는 블랙박스 기법
  • 경계값 분석: 입력의 경계 부근 값을 테스트하는 블랙박스 기법
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
