Q1

코드 출력 · C

다음 C 프로그램의 실행 결과를 출력하시오.

#include <stdio.h>

int main(void) {
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum += *(p + i);
        if (i % 2 == 0) {
            *(p + i) = *(p + i) + 1;
        }
    }

    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    printf("sum=%d\n", sum);

    return 0;
}
정답 보기 
11 20 31 40 51 
sum=150

sum은 수정 전 원래 값 10,20,30,40,50을 더해 150이 된다. i가 짝수(0,2,4)일 때만 해당 원소에 1을 더하므로 인덱스 0,2,4의 값이 각각 11, 31, 51로 바뀌고 나머지는 그대로 20, 40이다. 따라서 배열은 11 20 31 40 51이 출력된다.

Q2

코드 출력 · Python

다음 Python 프로그램의 실행 결과를 출력하시오.

def process(lst, idx, acc):
    if idx >= len(lst):
        return acc
    if lst[idx] % 2 == 0:
        acc.append(lst[idx] * 2)
    else:
        acc.append(lst[idx] + 1)
    return process(lst, idx + 1, acc)


numbers = [3, 4, 7, 8, 9]
result = process(numbers, 0, [])
print(result)

total = 0
for n in result:
    total += n
print(total)
정답 보기 
[4, 8, 8, 16, 10]
46

각 원소에 대해 짝수면 2배, 홀수면 1을 더한다: 3→4, 4→8, 7→8, 8→16, 9→10이 되어 result는 [4, 8, 8, 16, 10]이다. 이 리스트의 합은 4+8+8+16+10=46이다.

Q3

SQL 결과

다음 schema_sql로 테이블을 생성하고 데이터를 입력한 후, query_sql을 실행했을 때의 결과를 작성하시오.

-- schema
CREATE TABLE employee (
    emp_id INTEGER PRIMARY KEY,
    name TEXT,
    dept TEXT,
    salary INTEGER
);

INSERT INTO employee VALUES (1, '김철수', '영업', 3000);
INSERT INTO employee VALUES (2, '이영희', '영업', 3500);
INSERT INTO employee VALUES (3, '박민수', '개발', 4000);
INSERT INTO employee VALUES (4, '최지은', '개발', 4500);
INSERT INTO employee VALUES (5, '정우성', '개발', 5000);
INSERT INTO employee VALUES (6, '한소희', '인사', 3200);

-- query
SELECT dept, COUNT(*) AS cnt, SUM(salary) AS total_salary
FROM employee
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY total_salary DESC;
정답 보기 
dept | cnt | total_salary
개발 | 3 | 13500
영업 | 2 | 6500

GROUP BY dept로 부서별 그룹을 만들고 HAVING COUNT(*) >= 2 조건으로 인원이 2명 이상인 부서만 남긴다. 인사 부서는 1명이라 제외되고, 개발(3명, 합계 13500)과 영업(2명, 합계 6500)이 남으며 total_salary 내림차순으로 정렬되어 개발이 먼저 나온다.

Q5

용어 단답

소프트웨어 개발 과정에서 요구사항 분석, 설계, 구현, 테스트 등의 전체 과정을 짧은 주기(이터레이션)로 반복하면서 점진적으로 완성도를 높여가는 개발 방법론으로, 고객과의 지속적인 협업과 변화에 대한 유연한 대응을 강조하는 방법론을 무엇이라 하는가?

정답 보기 
애자일(Agile) 방법론

애자일 방법론은 폭포수 모델과 달리 짧은 반복 주기(스프린트)를 통해 소프트웨어를 점진적으로 개발하며, 고객 피드백을 빠르게 반영하고 변화하는 요구사항에 유연하게 대응하는 것을 핵심 가치로 한다. 대표적으로 스크럼(Scrum), XP(eXtreme Programming) 등이 있다.
