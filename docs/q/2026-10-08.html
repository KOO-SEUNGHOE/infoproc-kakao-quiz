Q1

코드 출력 · Java

다음 Java 프로그램의 실행 결과를 예측하시오.

public class Main {
    static int process(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] % 2 == 0) {
                sum += arr[i];
            } else {
                sum -= arr[i];
            }
        }
        return sum;
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5, 6};
        int result = process(numbers);
        System.out.println("result = " + result);

        int count = 0;
        for (int n : numbers) {
            if (n > 2) {
                count++;
            }
        }
        System.out.println("count = " + count);
    }
}
정답 보기 
result = 3
count = 4

배열 {1,2,3,4,5,6}에서 짝수(2,4,6)는 더하고 홀수(1,3,5)는 뺀다. 짝수 합은 12, 홀수 합은 9이므로 12-9=3이 result이다. 2보다 큰 원소는 3,4,5,6으로 총 4개이므로 count는 4이다.

Q2

코드 출력 · Python

다음 Python 프로그램의 실행 결과를 예측하시오.

def transform(lst):
    result = []
    for x in lst:
        if x % 3 == 0:
            result.append(x * 2)
        else:
            result.append(x + 1)
    return result


data = [1, 2, 3, 4, 5, 6, 9]
output = transform(data)
print(output)

total = sum(output)
print(total)

filtered = [v for v in output if v > 5]
print(filtered)
정답 보기 
[2, 3, 6, 5, 6, 12, 18]
52
[6, 6, 12, 18]

각 원소에 대해 3의 배수면 2배, 아니면 1을 더한다. 1→2, 2→3, 3→6, 4→5, 5→6, 6→12, 9→18이 되어 [2,3,6,5,6,12,18]이 나온다. 이 리스트의 합은 2+3+6+5+6+12+18=52이며, 5보다 큰 값만 필터링하면 [6,6,12,18]이다.

다음 schema_sql과 query_sql을 참고하여 쿼리의 실행 결과를 예측하시오.

-- schema
CREATE TABLE employee (
    emp_id INTEGER PRIMARY KEY,
    name TEXT,
    dept TEXT,
    salary INTEGER
);

INSERT INTO employee VALUES (1, '김철수', '영업', 3000);
INSERT INTO employee VALUES (2, '이영희', '영업', 3500);

INSERT INTO employee VALUES (5, '정수진', '개발', 5000);
INSERT INTO employee VALUES (6, '한가영', '인사', 2800);

-- query
SELECT dept, COUNT(*) AS cnt, AVG(salary) AS avg_sal
FROM employee
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY avg_sal DESC;
정답 보기 
dept | cnt | avg_sal
개발 | 3 | 4500.0
영업 | 2 | 3250.0

인사 부서는 직원이 1명이므로 HAVING COUNT(*) >= 2 조건에 의해 제외된다. 개발 부서는 3명(4000,4500,5000)으로 평균 4500, 영업은 2명(3000,3500)으로 평균 3250이다. 평균 급여 내림차순으로 정렬하면 개발이 먼저, 영업이 다음에 나온다.

정답 보기 
제2정규형(2NF)

제1정규형을 만족한 릴레이션에서 기본키의 일부 속성에만 종속되는 부분 함수 종속을 제거하면 제2정규형이 된다. 이는 복합키를 가진 테이블에서 데이터 중복과 이상현상을 줄이기 위한 단계이다.
