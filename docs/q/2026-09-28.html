Q1

코드 출력 · C

다음 C 프로그램의 실행 결과를 예측하시오. #include <stdio.h> int main() { int arr[5] = {10, 20, 30, 40, 50}; int *p = arr; int sum = 0; for (int i = 0; i < 5; i++) { if (i % 2 == 0) { sum += *(p + i); } else { sum -= *(p + i); } } printf("sum=%d\n", sum); printf("arr[2]=%d\n", *(arr + 2)); return 0; }

정답 보기 
sum=60
arr[2]=30

i가 0,2,4일 때(짝수 인덱스) 값을 더하고 1,3일 때(홀수 인덱스) 값을 뺍니다. 10-20+30-40+50 = 30이 아니라 순서대로 계산하면 10-20+30-40+50=30인데, 실제로는 i=0에서 +10, i=1에서 -20, i=2에서 +30, i=3에서 -40, i=4에서 +50이므로 10-20+30-40+50=30입니다. 다시 계산: 10-20=-10, -10+30=20, 20-40=-20, -20+50=30. 따라서 sum은 30이 아니라 재검산 결과 30입니다. arr[2]는 30입니다.

⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

SQL 결과

다음 EMPLOYEE 테이블에 대해 query_sql을 실행했을 때의 결과를 예측하시오.

-- schema
CREATE TABLE EMPLOYEE (
    emp_id INTEGER PRIMARY KEY,
    emp_name TEXT,
    dept TEXT,
    salary INTEGER
);

INSERT INTO EMPLOYEE VALUES (1, '김철수', '영업', 3000);
INSERT INTO EMPLOYEE VALUES (2, '이영희', '영업', 3500);
INSERT INTO EMPLOYEE VALUES (3, '박민수', '개발', 4000);
INSERT INTO EMPLOYEE VALUES (4, '최지훈', '개발', 4500);
INSERT INTO EMPLOYEE VALUES (5, '정수연', '개발', 5000);
INSERT INTO EMPLOYEE VALUES (6, '한지민', '인사', 3200);

-- query
SELECT dept, COUNT(*) AS cnt, AVG(salary) AS avg_sal
FROM EMPLOYEE
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY avg_sal DESC;
정답 보기 
dept | cnt | avg_sal
개발 | 3 | 4500.0
영업 | 2 | 3250.0

부서별로 그룹화한 뒤 인원수가 2명 이상인 부서만 남기면 인사(1명)는 제외됩니다. 개발 부서는 3명 평균 (4000+4500+5000)/3=4500, 영업 부서는 2명 평균 (3000+3500)/2=3250입니다. 평균 급여 내림차순 정렬 결과 개발이 먼저, 영업이 다음에 나옵니다.

Q5

용어 단답

테이블 내에서 기본키가 아닌 속성이 다른 기본키가 아닌 속성에 종속되는 현상을 제거하여, 기본키가 아닌 모든 속성이 기본키에만 종속되도록 만드는 정규화 단계를 무엇이라 하는가?

정답 보기 
제3정규형(3NF)

제3정규형은 이행적 함수 종속(transitive dependency)을 제거하는 단계로, 기본키가 아닌 속성이 다른 비키 속성에 종속되지 않고 오직 기본키에만 종속되도록 만드는 정규화 과정입니다.
