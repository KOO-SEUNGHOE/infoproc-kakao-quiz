Q1

코드 출력 · Python

다음 Python 코드의 실행 결과를 예측하시오.

def modify(lst, value):
    result = []
    for item in lst:
        if item % 2 == 0:
            result.append(item + value)
        else:
            result.append(item - value)
    return result


numbers = [1, 2, 3, 4, 5]
updated = modify(numbers, 10)
total = 0
for n in updated:
    total += n

print(updated)
print(total)
정답 보기 
[-9, 12, -7, 14, -5]
5

홀수는 value(10)를 빼고 짝수는 value(10)를 더합니다. 1->-9, 2->12, 3->-7, 4->14, 5->-5가 되어 리스트는 [-9, 12, -7, 14, -5]입니다. 이 값들의 합은 -9+12-7+14-5=5이므로 total은 5가 출력됩니다.

Q2

코드 출력 · Java

다음 Java 코드의 실행 결과를 예측하시오.

public class Main {
    static int process(int[] arr, int idx) {
        if (idx >= arr.length) {
            return 0;
        }
        int current = arr[idx];
        if (current % 3 == 0) {
            arr[idx] = current * 2;
        } else {
            arr[idx] = current + 1;
        }
        return arr[idx] + process(arr, idx + 1);
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5, 6};
        int sum = process(numbers, 0);
        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
        System.out.println();
        System.out.println(sum);
    }
}
정답 보기 
2 3 6 5 6 12 
34

재귀적으로 배열의 각 원소를 처리합니다: 1->2(3으로 안나눠짐,+1), 2->3(+1), 3->6(3배수,*2), 4->5(+1), 5->6(+1), 6->12(3배수,*2). 변경된 배열은 [2,3,6,5,6,12]이고, 반환값의 합(각 단계의 arr[idx] 합)은 2+3+6+5+6+12=34입니다.

Q3

SQL 결과

다음 schema_sql로 테이블을 생성하고 데이터를 입력했을 때, query_sql의 실행 결과를 예측하시오.

-- schema
CREATE TABLE orders (
    order_id INTEGER PRIMARY KEY,
    customer VARCHAR(20),
    amount INTEGER
);

INSERT INTO orders VALUES (1, 'Kim', 5000);
INSERT INTO orders VALUES (2, 'Lee', 3000);
INSERT INTO orders VALUES (3, 'Kim', 7000);
INSERT INTO orders VALUES (4, 'Park', 2000);
INSERT INTO orders VALUES (5, 'Lee', 6000);
INSERT INTO orders VALUES (6, 'Kim', 1000);
INSERT INTO orders VALUES (7, 'Park', 9000);

-- query
SELECT customer, COUNT(*) AS cnt, SUM(amount) AS total
FROM orders
GROUP BY customer
HAVING SUM(amount) >= 10000
ORDER BY total DESC;
정답 보기 
customer | cnt | total
Kim | 3 | 13000
Park | 2 | 11000

customer별로 그룹화하여 개수와 합계를 구합니다. Kim은 5000+7000+1000=13000, Lee는 3000+6000=9000, Park은 2000+9000=11000입니다. HAVING 조건으로 합계 10000 이상인 Kim과 Park만 남고, total 내림차순으로 정렬되어 Kim이 먼저, Park이 다음에 나옵니다.

Q4

용어 단답

릴레이션에서 기본키가 아닌 속성이 기본키 전체에 종속되지 않고, 기본키의 일부에만 종속되는 부분 함수 종속성을 제거하여 완전 함수 종속 관계로 만드는 정규화 단계를 무엇이라 하는가?

정답 보기 
제2정규형(2NF)

제2정규형은 제1정규형을 만족하면서 기본키가 아닌 모든 속성이 기본키에 완전 함수 종속되도록 부분 함수 종속을 제거하는 정규화 단계입니다. 이를 통해 데이터 중복과 이상 현상을 줄일 수 있습니다.
