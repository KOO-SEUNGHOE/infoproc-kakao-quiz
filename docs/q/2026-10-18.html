2026-10-18 실기 문제

Q1

용어 단답

소프트웨어 형상 관리(SCM)에서, 정식으로 검토되고 승인되어 이후 변경 시 공식적인 절차를 거쳐야만 수정할 수 있는 형상 항목의 기준점을 무엇이라 하는가?

정답 보기 
베이스라인(Baseline)

베이스라인은 소프트웨어 개발 과정에서 특정 시점에 공식적으로 검토 및 승인되어 고정된 형상 항목의 기준선을 의미합니다. 베이스라인이 설정된 이후에는 형상 항목을 임의로 변경할 수 없고, 반드시 형상통제위원회(CCB) 등의 공식적인 변경 관리 절차를 거쳐야 수정이 가능합니다. 이는 요구사항 베이스라인, 설계 베이스라인, 제품 베이스라인 등 개발 단계별로 설정될 수 있으며, 형상 관리의 4대 활동(형상 식별, 형상 통제, 형상 상태 기록, 형상 감사) 중 형상 통제의 기준점 역할을 합니다. 실기 시험에서는 '버전관리'나 '소스코드 관리'와 혼동하지 않도록 주의해야 하며, 베이스라인은 변경 통제의 '기준'이라는 개념이 핵심입니다.

📎 함께 암기하기
  • 형상 식별: 형상 항목을 식별하고 명명하는 활동
  • 형상 통제: 변경 요청을 검토하고 승인/반려하는 활동
  • 형상 감사: 베이스라인의 무결성을 검증하는 활동
  • 형상 상태 기록: 형상 항목의 변경 이력을 기록 및 보고하는 활동
  • CCB(형상통제위원회): 변경 승인 여부를 결정하는 공식 조직
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

Q2

용어 단답

디자인 패턴 중, 특정 클래스의 인스턴스가 오직 하나만 생성되도록 보장하고 어디서든 그 인스턴스에 전역적으로 접근할 수 있게 하는 생성 패턴은 무엇인가?

정답 보기 
싱글톤 패턴(Singleton Pattern)

싱글톤 패턴은 GoF 디자인 패턴 중 생성(Creational) 패턴에 속하며, 클래스의 인스턴스를 오직 하나만 생성하여 메모리 낭비를 방지하고 전역에서 동일한 객체에 접근하도록 보장합니다. 보통 생성자를 private으로 막고, 클래스 내부에 static 메서드(예: getInstance())를 통해 유일한 인스턴스를 반환하는 방식으로 구현합니다. 데이터베이스 커넥션 풀이나 설정 정보 관리 객체처럼 하나만 존재해야 하는 자원을 관리할 때 주로 사용됩니다. 실기에서는 팩토리 패턴(객체 생성을 서브클래스에 위임)이나 옵저버 패턴(상태 변화를 통지)과 혼동하지 않도록 생성 패턴 중에서도 '유일한 인스턴스 보장'이라는 특징을 정확히 기억해야 합니다.

📎 함께 암기하기
  • 팩토리 메서드 패턴: 객체 생성을 서브클래스가 결정하도록 위임하는 생성 패턴
  • 옵저버 패턴: 상태 변화를 관찰자들에게 통지하는 행위 패턴
  • 어댑터 패턴: 호환되지 않는 인터페이스를 연결해주는 구조 패턴
  • 빌더 패턴: 복잡한 객체 생성 과정을 단계별로 분리하는 생성 패턴
  • 데코레이터 패턴: 객체에 동적으로 기능을 추가하는 구조 패턴
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
