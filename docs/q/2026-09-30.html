Q1

코드 출력 · Java

다음 Java 프로그램을 실행했을 때 출력되는 결과를 작성하시오.

public class Main {
    static int process(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] % 2 == 0) {
                sum += arr[i];
            } else {
                sum -= arr[i];
            }
        }
        return sum;
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5, 6};
        int result = process(numbers);
        System.out.println("result: " + result);

        int total = 0;
        for (int n : numbers) {
            total += n;
        }
        System.out.println("total: " + total);
    }
}
정답 보기 
result: 3
total: 21

process 메서드는 짝수는 더하고 홀수는 빼는데, 짝수 합(2+4+6=12)에서 홀수 합(1+3+5=9)을 빼면 3이 아니라 12-9=3... 계산을 다시 확인하면 -1+2-3+4-5+6=3이 아니라 순서대로 계산 시 0-1=-1, -1+2=1, 1-3=-2, -2+4=2, 2-5=-3, -3+6=3이므로 result는 3이다. total은 배열 전체 합인 1+2+3+4+5+6=21이다.

Q2

코드 출력 · Python

다음 Python 코드를 실행했을 때 출력되는 결과를 작성하시오.

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)


def process(nums):
    result = []
    for n in nums:
        if n % 2 == 0:
            result.append(factorial(n))
        else:
            result.append(n * n)
    return result


data = [1, 2, 3, 4, 5]
output = process(data)
print(output)

total = sum(output)
print(total)
정답 보기 
[1, 2, 9, 24, 25]
61

1은 홀수이므로 1*1=1, 2는 짝수이므로 factorial(2)=2, 3은 홀수이므로 3*3=9, 4는 짝수이므로 factorial(4)=24, 5는 홀수이므로 5*5=25가 되어 리스트는 [1, 2, 9, 24, 25]이다. 이들의 합은 1+2+9+24+25=61이다.

Q3

SQL 결과

다음 스키마와 데이터를 바탕으로 query_sql을 실행했을 때의 결과를 작성하시오.

-- schema
CREATE TABLE orders (
    order_id INTEGER PRIMARY KEY,
    customer TEXT,
    amount INTEGER
);

INSERT INTO orders (order_id, customer, amount) VALUES (1, 'A', 5000);
INSERT INTO orders (order_id, customer, amount) VALUES (2, 'B', 3000);
INSERT INTO orders (order_id, customer, amount) VALUES (3, 'A', 7000);
INSERT INTO orders (order_id, customer, amount) VALUES (4, 'C', 2000);
INSERT INTO orders (order_id, customer, amount) VALUES (5, 'B', 6000);
INSERT INTO orders (order_id, customer, amount) VALUES (6, 'A', 1000);

-- query
SELECT customer, SUM(amount) AS total_amount, COUNT(*) AS cnt
FROM orders
GROUP BY customer
HAVING SUM(amount) >= 5000
ORDER BY total_amount DESC;
정답 보기 
customer | total_amount | cnt
A | 13000 | 3
B | 9000 | 2

고객별로 amount를 합산하면 A는 5000+7000+1000=13000(3건), B는 3000+6000=9000(2건), C는 2000(1건)이다. HAVING 조건으로 합계가 5000 이상인 A와 B만 남고, total_amount 기준 내림차순으로 정렬하면 A, B 순서가 된다.

용어 단답

관계형 데이터베이스에서 하나의 릴레이션에 있는 속성들 간에 기본키가 아닌 속성이 다른 기본키가 아닌 속성에 종속되는 현상을 제거하여, 이행적 함수 종속을 제거하는 정규화 단계를 무엇이라 하는가?

정답 보기 
제3정규형(3NF)

제3정규형은 제2정규형을 만족하면서 기본키가 아닌 모든 속성이 기본키에 대해 이행적 함수 종속이 되지 않도록 하는 정규화 단계이다. 즉, A→B, B→C인 경우 A→C의 이행적 종속을 제거하는 과정이다.
