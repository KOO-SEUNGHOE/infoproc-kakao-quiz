2026-10-27 실기 문제

Q1

용어 단답

정규화가 제대로 이루어지지 않은 릴레이션에서 데이터를 삽입, 삭제, 갱신할 때 발생할 수 있는 바람직하지 않은 현상을 통틀어 이르는 용어는 무엇인가? (삽입/삭제/갱신 각각의 명칭도 함께 서술하시오)

정답 보기 
이상 현상(Anomaly) — 삽입 이상(Insertion Anomaly), 삭제 이상(Deletion Anomaly), 갱신 이상(Update Anomaly)

이상 현상은 하나의 릴레이션에 여러 종류의 사실(정보)이 함께 저장되어 함수 종속 관계가 복잡할 때 발생하는 데이터 불일치 문제를 말한다. 삽입 이상은 특정 데이터를 입력하려 할 때 불필요한 다른 속성값까지 함께 입력해야 하거나 입력 자체가 불가능한 상황을 의미하며, 삭제 이상은 한 튜플을 삭제할 때 꼭 필요한 다른 정보까지 함께 손실되는 현상이다. 갱신 이상은 중복 저장된 값 중 일부만 수정되어 데이터 간 불일치가 발생하는 경우를 말한다. 이러한 이상 현상을 제거하기 위해 정규화를 수행하며, 1NF에서는 원자값 보장, 2NF에서는 부분 함수 종속 제거, 3NF에서는 이행 함수 종속 제거, BCNF에서는 모든 결정자가 후보키가 되도록 분해한다. 실기에서는 각 정규형의 조건과 이상 현상의 종류를 혼동하지 않고 정확히 구분해서 서술하는 것이 중요하다.

📎 함께 암기하기
  • 1NF: 모든 속성이 원자값(더 이상 분해 불가)을 가짐
  • 2NF: 1NF 만족 + 부분 함수 종속 제거(완전 함수 종속)
  • 3NF: 2NF 만족 + 이행 함수 종속 제거
  • BCNF: 모든 결정자가 후보키인 강한 3NF
  • 함수 종속: 속성 간 종속 관계로 정규화 판단 기준
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

Q2

용어 단답

트랜잭션이 성공적으로 완료된 후에도 데이터베이스가 일관된 상태를 유지해야 한다는 ACID의 특성은 무엇이며, 이 특성이 보장되지 않으면 발생할 수 있는 문제를 간단히 설명하시오.

정답 보기 
일관성(Consistency)

일관성은 트랜잭션 실행 전후에 데이터베이스가 정의된 무결성 제약조건(도메인, 키, 참조 무결성 등)을 항상 만족하는 상태로 유지되어야 한다는 특성이다. 만약 일관성이 보장되지 않으면 트랜잭션 수행 결과로 외래키 참조가 깨지거나 제약조건을 위반하는 값이 저장되어 데이터베이스의 신뢰성이 무너질 수 있다. ACID는 원자성(Atomicity, 트랜잭션의 연산은 모두 수행되거나 전혀 수행되지 않음), 일관성(Consistency), 고립성(Isolation, 동시 실행 트랜잭션이 서로 영향을 주지 않음), 지속성(Durability, 커밋된 결과는 영구 반영됨)으로 구성된다. 실기에서는 일관성과 고립성을 혼동하기 쉬운데, 일관성은 데이터의 논리적 제약조건 유지에 초점이 있고 고립성은 동시성 제어(병행 수행 트랜잭션 간 간섭 차단)에 초점이 있다는 점을 구분해야 한다. 또한 인덱스는 트랜잭션의 일관성과 별개로 조회 성능 향상을 위한 자료구조(B-Tree, Hash 등)이며, 과도한 인덱스는 삽입/갱신 시 오버헤드를 증가시켜 트랜잭션 성능에 영향을 줄 수 있다는 점도 함께 기억해야 한다.

📎 함께 암기하기
  • 원자성(Atomicity): 트랜잭션 전부 수행 또는 전혀 수행되지 않음
  • 고립성(Isolation): 병행 수행 트랜잭션 간 상호 간섭 차단
  • 지속성(Durability): 커밋 결과의 영구적 반영
  • 인덱스: B-Tree, Hash 기반 조회 성능 향상 자료구조
  • 병행 제어: 로킹, 타임스탬프 기법으로 고립성 보장
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
