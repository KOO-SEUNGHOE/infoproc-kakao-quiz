Q1

코드 출력 · Python

다음 파이썬 코드를 실행했을 때 출력되는 결과를 쓰시오.

def modify_list(lst):
    lst.append(100)
    lst[0] = lst[0] * 2
    return lst
numbers = [1, 2, 3]
result = modify_list(numbers)
print(numbers)
print(result)
total = 0
for n in result:
    if n % 2 == 0:
        total += n
print(total)
정답 보기 
[2, 2, 3, 100]
[2, 2, 3, 100]
104

리스트는 가변 객체이므로 함수 내부에서 append와 인덱스 변경을 하면 원본 numbers도 동일하게 변경되어 numbers와 result는 같은 객체 [2, 2, 3, 100]을 출력한다. 이후 짝수(2, 2, 100)만 더하면 2+2+100=104가 된다.

Q2

코드 출력 · C

다음 C 코드를 실행했을 때 출력되는 결과를 쓰시오.

#include <stdio.h>

int main(void) {
  int arr[5] = {10, 20, 30, 40, 50};
  int *p = arr;
  int sum = 0;

  for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) {
      sum += *(p + i);
    } else {
      sum -= *(p + i);
    }
  }

  printf("%d\n", sum);
  printf("%d\n", *p + *(p + 4));

  return 0;
}
정답 보기 
30
60

i가 0,2,4일 때는 더하고 1,3일 때는 빼므로 10-20+30-40+50=30... 다시 계산하면 10(더함)-20(뺌)+30(더함)-40(뺌)+50(더함)=30. 실제 계산: 10-20+30-40+50 = 30이 아니라 순서대로 10-20=-10, -10+30=20, 20-40=-20, -20+50=30이므로 sum은 30이다. *p는 arr[0]=10, *(p+4)는 arr[4]=50이므로 합은 60이다.

-- query
SELECT dept, COUNT(*) AS cnt, SUM(salary) AS total_salary
FROM employee
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY total_salary DESC;

부서별로 그룹화한 후 인원이 2명 이상인 부서만 필터링하면 총무(1명)는 제외된다. 개발은 3명에 급여 합계 13500, 영업은 2명에 급여 합계 6500이며, 총 급여 기준 내림차순 정렬이므로 개발이 먼저 나온다.
