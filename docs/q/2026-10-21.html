2026-10-21 실기 문제

Q1

용어 단답

UML 다이어그램 중, 객체들 사이에서 주고받는 메시지를 시간 흐름에 따라 세로축(생명선)과 가로축(메시지 순서)으로 표현하여 상호작용을 나타내는 다이어그램의 이름을 쓰시오.

정답 보기 
시퀀스 다이어그램(Sequence Diagram)

시퀀스 다이어그램은 UML의 행위(동적) 다이어그램 중 하나로, 객체를 세로선(라이프라인)으로 나타내고 시간의 흐름에 따라 객체 간에 주고받는 메시지를 가로 화살표로 표현합니다. 활성화 구간(activation bar)을 통해 특정 객체가 언제부터 언제까지 실행 상태인지도 나타낼 수 있어 시스템의 동작 순서를 세밀하게 분석할 때 사용됩니다. 비슷한 상호작용을 표현하는 커뮤니케이션 다이어그램과 자주 비교되는데, 커뮤니케이션 다이어그램은 시간 순서보다 객체 간의 연결 관계(링크)를 중심으로 표현한다는 차이가 있습니다. 정보처리기사 실기에서는 UML 다이어그램을 구조적 다이어그램과 행위적 다이어그램으로 분류하는 문제와 함께 자주 출제되므로 분류 기준을 명확히 알아두어야 합니다.

📎 함께 암기하기
  • 클래스 다이어그램: 시스템의 정적 구조를 클래스와 관계로 표현하는 구조적 다이어그램
  • 커뮤니케이션 다이어그램: 객체 간 메시지를 링크 중심으로 표현하는 행위 다이어그램
  • 유스케이스 다이어그램: 시스템과 액터 간의 기능적 상호작용을 표현하는 행위 다이어그램
  • 상태 다이어그램: 객체의 상태 변화를 이벤트에 따라 표현하는 행위 다이어그램
  • 액티비티 다이어그램: 업무 처리 흐름을 순서도 형태로 표현하는 행위 다이어그램
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.

Q2

용어 단답

데이터베이스에서 참조하는 테이블의 기본키(또는 후보키)에 없는 값은 외래키 칼럼에 입력할 수 없도록 보장하여, 두 테이블 간의 참조 관계가 항상 일관되게 유지되도록 하는 무결성 제약조건의 이름을 쓰시오.

정답 보기 
참조 무결성(Referential Integrity)

참조 무결성은 외래키(Foreign Key) 값이 반드시 참조되는 테이블의 기본키 값 중 하나와 일치하거나 NULL이어야 한다는 제약조건으로, 이를 통해 존재하지 않는 참조 대상을 가리키는 '고아 레코드'가 생기지 않도록 보장합니다. 이 제약조건이 위반되는 상황은 참조하는 테이블에 없는 값을 자식 테이블에 삽입하려 하거나, 부모 테이블의 레코드를 삭제했는데 이를 참조하는 자식 레코드가 남아있을 때 발생하며, 이를 방지하기 위해 CASCADE, SET NULL, RESTRICT 같은 참조 동작 옵션을 지정할 수 있습니다. 개체 무결성(Entity Integrity)이 기본키는 NULL이 될 수 없고 중복될 수 없다는 규칙인 것과 달리, 참조 무결성은 테이블 간의 관계를 다루는 제약조건이라는 점에서 구분해야 합니다. 정보처리기사 실기에서는 도메인 무결성, 개체 무결성, 참조 무결성을 구분하는 문제와 CASCADE/SET NULL 옵션의 동작 차이를 묻는 문제가 함께 출제되는 경향이 있습니다.

📎 함께 암기하기
  • 개체 무결성: 기본키는 NULL이 될 수 없고 중복되지 않아야 함
  • 도메인 무결성: 속성 값이 정의된 도메인(자료형, 범위) 내에 있어야 함
  • 외래키(Foreign Key): 다른 테이블의 기본키를 참조하는 속성
  • CASCADE: 부모 레코드 삭제/수정 시 자식 레코드도 연쇄적으로 삭제/수정되는 옵션
  • NOT NULL 제약조건: 특정 칼럼에 NULL 값 입력을 금지하는 제약
⚠ 자동 실행 검증이 되지 않은 문제입니다. 정답이 의심되면 교재로 한 번 더 확인하세요.
